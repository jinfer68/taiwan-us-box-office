# 台美票房落差

同一部好萊塢片，在台灣和美國的票房表現可能完全不同。這個互動網頁比對 2016 年 6 月以來在台灣上映、票房破千萬的 499 部美國片，算出每部片「在台灣比預期多賣或少賣幾倍」，並分析造成差異的原因；另外比較 Netflix 台灣與全球的前十名。

**網頁：https://jinfer68.github.io/taiwan-us-box-office/**

課程「影視幕後的商業運作」作業一的延伸分析。

## 內容

- **散佈圖與排行榜**：依美國本土票房推算台灣預期票房（對數迴歸），找出台灣表現特別好或特別差的片。
- **為什麼會偏離**：類型、各國票房相關性、明星與導演、上映時間差、製作規模、IMDb 評分。
- **Netflix 台灣 vs 全球**：台灣榜與全球榜的重疊率、最相似的國家、作品來源組成、逐年趨勢、院線片接到串流的表現。
- **《沙丘：第二部》週票房定義**：台灣官方「週一至週日」與「上映日起算 7 天」的差異。
- **《臥虎藏龍》**：平台式發行的戲院數與票房曲線。

## 方法摘要

- 預期值：以非疫情期（排除 2020/3–2021/12 上映）460 部片估計 `ln(台灣票房) = 1.782 + 0.686 × ln(美國本土票房)`，R² = 0.38；殘差標準差約 ×2.38，「實際÷預期」在 0.42–2.38 之間視為正常範圍。
- 作品來源國依 Wikidata 的出品國與原始語言判定，約 85% 的 Netflix 上榜紀錄可辨識。
- 片名在不同資料庫之間以英文名稱與年份比對，已人工修正確認過的錯誤，仍可能有少量誤配。
